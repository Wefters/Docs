## Overview

iOS native plugin code resides inside `ios/*.swift` and extends `WefterPlugin`.

It uses `// @WefterMethod` comment markers to expose callable methods, `// @WefterHook` for native lifecycle hooks, `throws` for exception handling, and inherited `resolve`/`reject` methods.

---

## Complete Working iOS Swift Plugin Example

```swift
import Foundation
import AVFoundation

final class ScannerPlugin: WefterPlugin {

    // @WefterMethod
    func open(payload: [String: Any], callback: @escaping (Result<Any, Error>) -> Void) throws {
        // Step 1: Check iOS AVCaptureDevice camera authorization status
        switch AVCaptureDevice.authorizationStatus(for: .video) {
        case .authorized:
            startScanning(callback)

        case .notDetermined:
            AVCaptureDevice.requestAccess(for: .video) { [weak self] granted in
                DispatchQueue.main.async {
                    if granted {
                        self?.startScanning(callback)
                    } else {
                        self?.reject(callback, code: "PERMISSION_DENIED", message: "Camera permission was denied")
                    }
                }
            }

        case .denied, .restricted:
            reject(callback, code: "PERMISSION_DENIED", message: "Camera permission was denied")

        @unknown default:
            reject(callback, code: "PERMISSION_DENIED", message: "Camera permission was denied")
        }
    }

    // @WefterMethod
    func close(payload: [String: Any], callback: @escaping (Result<Any, Error>) -> Void) throws {
        resolve(callback, data: ["stopped": true])
    }

    // @WefterHook("appReady")
    func onAppReady() {
        // Native lifecycle hook triggered when web app completes initial load
    }

    private func startScanning(_ callback: @escaping (Result<Any, Error>) -> Void) {
        resolve(callback, data: ["started": true])

        // Emit real-time result event to JS listeners
        emit("scanner:result", ["code": "123456789"])
    }
}
```

## Core Swift Authoring Rules

1. **Comment Marker**: Precede native functions with `// @WefterMethod`.
2. **Mandatory `throws`**: Include the `throws` keyword on all `@WefterMethod` declarations.
3. **Required Signature**: Match parameter format: `(payload: [String: Any], callback: @escaping (Result<Any, Error>) -> Void)`.
4. **Never Force-Unwrap (`!`)**: Avoid `!` force-unwrapping and direct un-bounds dictionary subscripting to prevent unrecoverable Swift fatal traps.
5. **Main Thread UI Updates**: Always dispatch UI modifications or permission callbacks to `DispatchQueue.main.async`.
