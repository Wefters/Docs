## Overview

A Wefter native plugin package contains a manifest file (`plugin.json`), a TypeScript wrapper (`src/index.ts`), an npm manifest (`package.json`), and native source code for Android (`Kotlin`) and/or iOS (`Swift`).

---

## Supported Directory Layouts

Wefter supports three valid plugin package layouts. All three pass validation via `wefter plugin validate`:

### 1. Dual-Platform Plugin (Android & iOS)

```text
camera-plugin/
├── package.json          # NPM manifest declaring @wefterjs/core dependency
├── plugin.json           # Wefter plugin manifest (permissions, methods, dependencies)
├── README.md             # Plugin documentation
├── src/
│   └── index.ts          # TypeScript client API wrapper
├── android/              # Native Android Kotlin source files
│   └── CameraPlugin.kt
└── ios/                  # Native iOS Swift source files
    └── CameraPlugin.swift
```

### 2. Android-Only Plugin (`android/` only)

```text
camera-plugin/
├── package.json
├── plugin.json
├── README.md
├── src/
│   └── index.ts
└── android/
    └── CameraPlugin.kt
```

### 3. iOS-Only Plugin (`ios/` only)

```text
camera-plugin/
├── package.json
├── plugin.json
├── README.md
├── src/
│   └── index.ts
└── ios/
    └── CameraPlugin.swift
```

## File Roles & Responsibilities

| File / Folder Path | Role & Purpose                                                                                                                            |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `package.json`     | Standard npm package manifest. Must declare `@wefterjs/core` in `dependencies` or `peerDependencies` and define build scripts.            |
| `plugin.json`      | Wefter native manifest. Declares native permissions, Maven/SPM dependencies, manifest entries, and list of exported native methods/hooks. |
| `src/index.ts`     | The client-side TypeScript API exported to consuming web applications. Wraps `invokeNative` and `registerHook`.                           |
| `android/*.kt`     | Kotlin native source files extending `WefterPlugin`. Contains methods annotated with `@WefterMethod` or `@WefterHook`.                    |
| `ios/*.swift`      | Swift native source files extending `WefterPlugin`. Contains methods marked with `// @WefterMethod` or `// @WefterHook`.                  |
