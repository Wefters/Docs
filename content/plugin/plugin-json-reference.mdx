## Overview

The `plugin.json` manifest file resides at the root of every Wefter plugin package directory.

It defines native permissions, Gradle/SPM package dependencies, ProGuard rules, Android manifest components (Activities and Intent Filters), and declared `@WefterMethod`/`@WefterHook` method lists.

---

## Schema Reference Table

| Field Name                                 | Type                     | Required / Optional | Default Value | Description                                                                             |
| ------------------------------------------ | ------------------------ | ------------------- | ------------- | --------------------------------------------------------------------------------------- |
| `name`                                     | String                   | **Required**        | None          | Unique plugin package identifier (matches `wefter.config.json`'s `plugins` array).      |
| `permissions.android`                      | Array of Strings         | Optional            | `[]`          | List of Android manifest permission constants (`android.permission.CAMERA`).            |
| `permissions.ios`                          | `Record<string, string>` | Optional            | `{}`          | Key-value pairs mapping iOS `Info.plist` usage keys to user prompt description strings. |
| `nativeDependencies.android.gradle`        | Array of Strings         | Optional            | `[]`          | Maven Gradle dependency coordinates (`group:artifact:version`).                         |
| `nativeDependencies.android.proguardRules` | String                   | Optional            | None          | Raw ProGuard rules text merged into `proguard-rules.pro`.                               |
| `nativeDependencies.ios.spm`               | Array of Objects         | Optional            | `[]`          | Swift Package Manager dependencies (`url`, `from`, `product`).                          |
| `android.manifestEntries`                  | Array of Objects         | Optional            | `[]`          | Android manifest component entries (Activities and Intent Filters).                     |
| `methods`                                  | Array of Strings         | Optional            | `[]`          | List of `@WefterMethod` function names implemented by native source files.              |
| `hooks`                                    | Array of Strings         | Optional            | `[]`          | List of `@WefterHook` signal names implemented by native source files.                  |
| `events`                                   | Array of Strings         | Optional            | `[]`          | List of event names emitted by native plugin code (`emit`).                             |

## Field Details & Examples

### 1. `permissions`

```json
{
  "permissions": {
    "android": [
      "android.permission.CAMERA",
      "android.permission.ACCESS_FINE_LOCATION"
    ],
    "ios": {
      "NSCameraUsageDescription": "Allows taking photos inside the app.",
      "NSLocationWhenInUseUsageDescription": "Allows fetching location for tag generation."
    }
  }
}
```

### 2. `nativeDependencies`

```json
{
  "nativeDependencies": {
    "android": {
      "gradle": [
        "androidx.camera:camera-camera2:1.3.0",
        "com.google.mlkit:barcode-scanning:17.2.0"
      ],
      "proguardRules": "-keep class com.google.mlkit.** { *; }"
    },
    "ios": {
      "spm": [
        {
          "url": "https://github.com/google/GoogleSignIn-iOS",
          "from": "7.0.0",
          "product": "GoogleSignIn"
        }
      ]
    }
  }
}
```

### 3. `android.manifestEntries`

Declares native Android Activities and Intent Filters woven into `AndroidManifest.xml` during `wefter sync`:

```json
{
  "android": {
    "manifestEntries": [
      {
        "type": "activity",
        "name": ".AuthRedirectActivity",
        "exported": true,
        "intentFilters": [
          {
            "action": "android.intent.action.VIEW",
            "categories": [
              "android.intent.category.DEFAULT",
              "android.intent.category.BROWSABLE"
            ],
            "data": {
              "scheme": "${appScheme}"
            }
          }
        ]
      }
    ]
  }
}
```

<Callout type="info">
  **Manifest Placeholders**: `data.scheme` values containing `${placeholder}`
  variables resolve dynamically against `pluginConfig` in the host app's
  `wefter.config.json` during `wefter sync`.
</Callout>

### 4. `methods` & `hooks`

Lists annotated methods implemented in native source files. `wefter plugin validate` verifies 1:1 parity between declared method names and `@WefterMethod`/`@WefterHook` annotations in Kotlin/Swift source files:

```json
{
  "methods": ["open", "close", "takePhoto"],
  "hooks": ["appReady"],
  "events": ["photoCaptured"]
}
```

## Full `plugin.json` Example

```json
{
  "name": "camera-scanner",
  "permissions": {
    "android": ["android.permission.CAMERA"],
    "ios": {
      "NSCameraUsageDescription": "Required to scan barcodes."
    }
  },
  "nativeDependencies": {
    "android": {
      "gradle": ["androidx.camera:camera-camera2:1.3.0"],
      "proguardRules": "-keep class androidx.camera.** { *; }"
    },
    "ios": {
      "spm": []
    }
  },
  "android": {
    "manifestEntries": []
  },
  "methods": ["open", "close"],
  "hooks": [],
  "events": ["scanResult"]
}
```
