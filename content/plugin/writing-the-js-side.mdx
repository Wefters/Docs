## Overview

The `src/index.ts` file forms the client-side API exported by a Wefter plugin npm package.

It wraps low-level bridge functions (`invokeNative` and `registerHook` from `@wefterjs/core`) into strongly-typed TypeScript interfaces for web applications.

---

## 1. Typing Payload Arguments & Return Values

Because data payloads cross the native bridge serialized as JSON, export explicit TypeScript interfaces for options and result objects:

```ts
import { invokeNative } from "@wefterjs/core";

export interface ScanOptions {
  facing?: "front" | "back";
  torch?: boolean;
}

export interface ScanResult {
  code: string;
  format: string;
}

export const Scanner = {
  scan(options: ScanOptions = {}): Promise<ScanResult> {
    return invokeNative<ScanResult>("scanner", "scan", options);
  },
};
```

## 2. Event Namespacing Convention

Native event streams emitted via `emit(hookName, data)` share a global JavaScript event dispatcher map inside `@wefterjs/core`.

To prevent event name collisions between different installed plugins (e.g. two plugins emitting `"tick"` or `"result"`), **prefix all native event hook names with your plugin's name and a colon**:

```ts
import { registerHook } from "@wefterjs/core";

export interface ScanEvent {
  code: string;
}

export const Scanner = {
  // Public JS subscription method
  onResult(callback: (event: ScanEvent) => void): { remove(): void } {
    // Prefix internal hook name with 'scanner:'
    return registerHook("scanner:result", callback as (data: unknown) => void);
  },
};
```

In native Kotlin/Swift source, emit using the exact same prefixed string:

```kotlin
// Android Kotlin
emit("scanner:result", JSONObject().put("code", scannedCode))
```

```swift
// iOS Swift
emit("scanner:result", ["code": scannedCode])
```

## 3. Exposing Utility & Management APIs

Combine `definePlugin` with custom event handlers to construct complete plugin clients:

```ts
import { definePlugin, registerHook } from "@wefterjs/core";

export interface ScannerPluginInterface {
  open(): Promise<{ started: boolean }>;
  close(): Promise<{ stopped: boolean }>;
}

export const Scanner = {
  ...definePlugin<ScannerPluginInterface>("scanner", {
    open: true,
    close: true,
  }),

  onResult(callback: (event: { code: string }) => void) {
    return registerHook("scanner:result", callback as (data: unknown) => void);
  },
};
```
