## Overview

Android native plugin code resides inside `android/*.kt` and extends `WefterPlugin`.

It uses `@WefterMethod` annotations to expose callable methods to JavaScript, `@WefterHook` for native lifecycle hooks, and inherited `resolve`/`reject` methods to settle Promises.

---

## Complete Working Android Kotlin Plugin Example

```kotlin
package dev.wefter.bridge

import android.Manifest
import android.app.Activity
import android.content.Context
import org.json.JSONObject

class ScannerPlugin(context: Context, dispatcher: BridgeDispatcher) : WefterPlugin(context, dispatcher) {

    private val activity: Activity?
        get() = context as? Activity

    @WefterMethod
    fun open(payload: JSONObject, callback: (Result<Any>) -> Unit) {
        val currentActivity = activity
        if (currentActivity == null) {
            reject(callback, "NO_ACTIVITY", "Current Android Context is not an Activity")
            return
        }

        // Step 1: Check runtime camera permission
        if (hasPermission(Manifest.permission.CAMERA)) {
            startScanning(callback)
            return
        }

        // Step 2: Request runtime permission
        requestPermission(currentActivity, Manifest.permission.CAMERA) { granted ->
            if (granted) {
                startScanning(callback)
            } else {
                reject(callback, "PERMISSION_DENIED", "Camera permission was denied")
            }
        }
    }

    @WefterMethod
    fun close(payload: JSONObject, callback: (Result<Any>) -> Unit) {
        // Simple synchronous resolution
        resolve(callback, JSONObject().put("stopped", true))
    }

    @WefterHook("appReady")
    fun onAppReady() {
        // Native lifecycle hook triggered when web app completes initial load
    }

    private fun startScanning(callback: (Result<Any>) -> Unit) {
        // Perform native camera setup and resolve Promise
        resolve(callback, JSONObject().put("started", true))

        // Emit real-time result event to JS listeners
        emit("scanner:result", JSONObject().put("code", "123456789"))
    }
}
```

## Core Kotlin Authoring Rules

1. **Flexible Package Headers**: You can declare any package name (e.g. `package dev.wefter.bridge` or `package com.myorg.plugin`). `wefter sync` replaces `package <whatever>` with the host app's package namespace automatically.
2. **Annotate Methods**: Annotate public plugin functions with `@WefterMethod`.
3. **Required Signature**: Match parameter format: `(payload: JSONObject, callback: (Result<Any>) -> Unit)`.
4. **Settle Every Branch**: Ensure every conditional code path calls either `resolve(callback, data)` or `reject(callback, code, message)`. Paths that call neither leave JavaScript promises pending until the 10-second timeout.
5. **Handle Denials**: Declare dangerous permissions in `plugin.json` and handle denial results by returning `PERMISSION_DENIED`.
