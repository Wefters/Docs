## Overview

On both platforms, every Wefter native plugin extends `WefterPlugin`. The base class provides standard helper methods for resolving/rejecting asynchronous JavaScript calls, emitting real-time event hooks, and accessing host application resources (Android `Context` or iOS `UIViewController`).

---

## Android (`Kotlin`): `WefterPlugin`

```kotlin
package dev.wefter.bridge

import android.app.Activity
import android.content.Context
import org.json.JSONObject

abstract class WefterPlugin(
    protected val context: Context,
    protected val dispatcher: BridgeDispatcher
)
```

### Member Reference

| Member Name         | Method Signature                                                                                  | Description                                                                                  |
| ------------------- | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `resolve`           | `resolve(callback: (Result<Any>) -> Unit, data: JSONObject = JSONObject())`                       | Resolves the pending JS Promise with a successful payload.                                   |
| `reject`            | `reject(callback: (Result<Any>) -> Unit, code: String, message: String)`                          | Rejects the pending JS Promise with a structured [`WefterError`](/plugin/structured-errors). |
| `emit`              | `emit(hookName: String, data: JSONObject)`                                                        | Pushes an event payload to JavaScript listeners (`registerHook`).                            |
| `hasPermission`     | `hasPermission(permission: String): Boolean`                                                      | Checks if a runtime Android permission is granted (`ContextCompat.checkSelfPermission`).     |
| `requestPermission` | `requestPermission(activity: Activity, permission: String, onResult: (granted: Boolean) -> Unit)` | Requests a runtime permission and receives an asynchronous result callback.                  |

### Android Implementation Example

```kotlin
package dev.wefter.bridge

import android.content.Context
import org.json.JSONObject

class BatteryPlugin(context: Context, dispatcher: BridgeDispatcher) : WefterPlugin(context, dispatcher) {

    @WefterMethod
    fun getLevel(payload: JSONObject, callback: (Result<Any>) -> Unit) {
        val level = 85 // Read battery level from Android OS
        resolve(callback, JSONObject().put("level", level))
    }
}
```

## iOS (`Swift`): `WefterPlugin`

```swift
import Foundation
#if canImport(UIKit)
import UIKit
#endif

open class WefterPlugin {
    public let dispatcher: BridgeDispatcher
    public weak var viewController: UIViewController?

    public required init(dispatcher: BridgeDispatcher, viewController: UIViewController?)
}
```

### Member Reference

| Member Name      | Method Signature                                                                  | Description                                                                                      |
| ---------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `resolve`        | `resolve(_ callback: (Result<Any, Error>) -> Void, data: [String: Any] = [:])`    | Resolves the pending JS Promise with a successful dictionary payload.                            |
| `reject`         | `reject(_ callback: (Result<Any, Error>) -> Void, code: String, message: String)` | Rejects the pending JS Promise with a structured [`WefterError`](/plugin/structured-errors).     |
| `emit`           | `emit(_ hookName: String, _ data: [String: Any])`                                 | Pushes an event payload to JavaScript listeners (`registerHook`).                                |
| `viewController` | `public weak var viewController: UIViewController?`                               | Weak reference to host iOS `UIViewController` for presenting native dialogs or view controllers. |

### iOS Implementation Example

```swift
import Foundation

final class BatteryPlugin: WefterPlugin {

    // @WefterMethod
    func getLevel(payload: [String: Any], callback: @escaping (Result<Any, Error>) -> Void) throws {
        let level = 85
        resolve(callback, data: ["level": level])
    }
}
```

<Callout type="info">
  **Platform Parity Difference**: Android provides `hasPermission` and `requestPermission` on `WefterPlugin` because
  Android permissions share a single `PackageManager` callback model. iOS framework permissions (`AVCaptureDevice`,
  `CLLocationManager`, `PHPhotoLibrary`) each use distinct delegates, requiring plugin authors to call Apple's framework
  APIs directly.
</Callout>

## Reaching Plugin Instances: `WefterBridge`

When a plugin needs to communicate with external native activities, custom view controllers, or deep-link handlers outside of `WefterPlugin`, use `WefterBridge` to look up active plugin instances by name.

### Android

```kotlin
val plugin = WefterBridge.getPlugin("battery") as? BatteryPlugin
plugin?.emit("levelChanged", JSONObject().put("level", 90))
```

### iOS

```swift
if let plugin = WefterBridge.plugin(withId: "battery") as? BatteryPlugin {
    plugin.emit("levelChanged", ["level": 90])
}
```
