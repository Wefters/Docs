## Overview

The `@WefterMethod` marker designates native Kotlin and Swift functions that can be invoked from JavaScript via `invokeNative`.

During [`wefter sync`](/cli/sync) and [`wefter plugin validate`](/cli/plugin-validate), Wefter scans native source files for `@WefterMethod` declarations to generate typed native dispatchers (`<PluginName>PluginDispatch`) with **zero runtime reflection**.

---

## Kotlin (Android): `@WefterMethod`

In Kotlin, `@WefterMethod` is defined with `AnnotationRetention.SOURCE`, meaning it is processed during static codegen and erased before bytecode compilation.

### Required Signature Format

```kotlin
package dev.wefter.bridge

import org.json.JSONObject

class CameraPlugin(context: Context, dispatcher: BridgeDispatcher) : WefterPlugin(context, dispatcher) {

    @WefterMethod
    fun takePhoto(payload: JSONObject, callback: (Result<Any>) -> Unit) {
        val quality = payload.optInt("quality", 90)
        // ...
        resolve(callback, JSONObject().put("path", "/path/to/photo.jpg"))
    }
}
```

### Signature Requirements (Kotlin)

- **Annotation**: Must be preceded by `@WefterMethod`.
- **First Parameter**: Must be `payload: JSONObject` (contains arguments passed from JS).
- **Second Parameter**: Must be `callback: (Result<Any>) -> Unit` (used to invoke `resolve` or `reject`).

## Swift (iOS): `// @WefterMethod`

In Swift, the marker is written as a structured comment line `// @WefterMethod`.

### Required Signature Format

```swift
import Foundation

final class CameraPlugin: WefterPlugin {

    // @WefterMethod
    func takePhoto(payload: [String: Any], callback: @escaping (Result<Any, Error>) -> Void) throws {
        let quality = payload["quality"] as? Int ?? 90
        // ...
        resolve(callback, data: ["path": "/path/to/photo.jpg"])
    }
}
```

### Signature Requirements (Swift)

- **Comment Marker**: Must be preceded by `// @WefterMethod`.
- **First Parameter**: Must be `payload: [String: Any]`.
- **Second Parameter**: Must be `callback: @escaping (Result<Any, Error>) -> Void`.
- **Keyword**: Function must include the `throws` keyword.

<Callout type="important">
  **The `throws` Keyword in Swift**: The `throws` keyword is mandatory on Swift `@WefterMethod` declarations. If native
  Swift code throws an unhandled error inside a method body, the dispatcher catches it and returns a `WefterBridgeError`
  with code `"PLUGIN_THREW"` to JavaScript, preventing native crashes.
</Callout>

## Validation & Signature Matching

`wefter plugin validate` verifies that every method marked with `@WefterMethod` satisfies the exact parameter signature rules above.

| Platform             | Valid Signature Syntax                                                                                           |
| -------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Android (Kotlin)** | `@WefterMethod\nfun <name>(payload: JSONObject, callback: (Result<Any>) -> Unit)`                                |
| **iOS (Swift)**      | `// @WefterMethod\nfunc <name>(payload: [String: Any], callback: @escaping (Result<Any, Error>) -> Void) throws` |

If a method signature deviates from these shapes, `wefter plugin validate` fails with:

```text
[ERROR] Malformed @WefterMethod signature at line <n> (android/ / ios/)
```
