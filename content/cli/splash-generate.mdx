---
title: wefter splash generate
description: Scaffolds an example splash folder — no image source involved.
---

```bash
wefter splash generate [targetPath] [projectDir]
```

| Argument | Type | Default | Purpose |
| --- | --- | --- | --- |
| `targetPath` | positional, optional | `"splash"` | Where to write the scaffolded folder, relative to `projectDir`. |
| `projectDir` | positional, optional | current working directory | Project root. |

```bash
wefter splash generate
wefter splash generate ./resources/splash
```

Fails rather than overwriting if something's already at the destination:

```
<resolved path> already exists — remove it first or choose a different path.
```

## No image source — this scaffolds HTML, not icons

Unlike [`wefter icon generate`](/cli/icon-generate), this command takes
no source asset. Wefter's splash screen is developer-authored HTML, not
generated from an image, so what this command produces is a working
starting point you're expected to edit by hand, not a final asset. See
[App Splash Screen](/docs/app-splash-screen) on the Docs tab for the
full system this folder plugs into — two stages, folder validation, the
`hideSplash()` dismissal signal, `minDuration`/`maxDuration`/`dismissOn`.

## The exact scaffold written

`index.html`:

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <link rel="stylesheet" href="./styles.css">
</head>
<body>
  <div class="mark"></div>
</body>
</html>
```

`styles.css`:

```css
body {
  margin: 0;
  display: flex;
  align-items: center;
  justify-content: center;
  height: 100vh;
  background: #0F766E;
}
.mark {
  width: 72px;
  height: 72px;
  border-radius: 20px;
  background: #ffffff;
  animation: pulse 1.2s ease-in-out infinite;
}
@keyframes pulse {
  0%, 100% { opacity: 1; transform: scale(1); }
  50% { opacity: 0.7; transform: scale(0.92); }
}
```

A centered, pulsing mark on a solid teal background — meant to be
replaced, not shipped as-is.

## Wiring it up

Scaffolding the folder alone doesn't enable the splash screen. Point
`wefter.config.json` at it, then sync:

```json
{
  "splash": {
    "source": "splash",
    "minDuration": 400,
    "maxDuration": 5000,
    "dismissOn": "ready",
    "transition": "fade"
  }
}
```

```bash
wefter sync
```

`minDuration`, `maxDuration`, `dismissOn`, and `transition` are all
optional; full field reference on [App
Configuration](/docs/app-configuration#splash). The CLI's success output
after `splash generate` reminds you of the exact config shape:

```
Scaffolded /path/to/project/splash
Set "splash": { "source": "splash" } in wefter.config.json, then `wefter sync`.
```
