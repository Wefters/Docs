## Synopsis

```bash
wefter splash generate [targetPath] [projectDir]
```

## Overview & Use Cases

`wefter splash generate` scaffolds an HTML/CSS splash screen directory template with animated CSS styling (`index.html` and `styles.css`).

Unlike traditional native splash screens that require static image PNG files, Wefter renders custom developer-authored HTML/CSS splash screens natively before handing off control to your web application.

### Primary Use Cases

- Generating a starter HTML/CSS splash screen folder template.
- Creating a custom animated loading screen for web-to-native app startup.

---

## What It Does

When invoked, `wefter splash generate` executes the following sequence:

1. **Path Availability Check**: Resolves `targetPath` relative to `projectDir`. Fails if the target directory already exists to prevent accidental overwrites.
2. **Directory Creation**: Creates `targetPath` folder recursively.
3. **Template Scaffolding**: Writes starter files:
   - **`index.html`**: HTML structure containing a centered branding mark container `<div class="mark"></div>`.
   - **`styles.css`**: CSS stylesheet containing responsive flexbox centering, background styling (`#0F766E`), and keyframe pulse animation.
4. **Configuration Guidance Output**: Logs instructions for declaring the splash screen in `wefter.config.json`.

---

## Arguments & Options

### Arguments

| Argument     | Type       | Required / Optional | Description                                                                   | Default                                     |
| ------------ | ---------- | ------------------- | ----------------------------------------------------------------------------- | ------------------------------------------- |
| `targetPath` | Positional | Optional            | Output folder path for scaffolded splash template (relative to `projectDir`). | `"splash"`                                  |
| `projectDir` | Positional | Optional            | Path to project root directory.                                               | Current working directory (`process.cwd()`) |

### Options (Flags)

`wefter splash generate` does not accept flags.

## Usage Examples

### Scaffold Splash Screen in Default `splash/` Folder

```bash
wefter splash generate
```

### Scaffold Splash Screen in Custom Directory

```bash
wefter splash generate ./resources/my-splash
```

## Scaffolded Template Code

### `index.html`

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8" />
    <link rel="stylesheet" href="./styles.css" />
  </head>
  <body>
    <div class="mark"></div>
  </body>
</html>
```

### `styles.css`

```css
body {
  margin: 0;
  display: flex;
  align-items: center;
  justify-content: center;
  height: 100vh;
  background: #0f766e;
}
.mark {
  width: 72px;
  height: 72px;
  border-radius: 20px;
  background: #ffffff;
  animation: pulse 1.2s ease-in-out infinite;
}
@keyframes pulse {
  0%,
  100% {
    opacity: 1;
    transform: scale(1);
  }
  50% {
    opacity: 0.7;
    transform: scale(0.92);
  }
}
```

## Enabling in `wefter.config.json`

After scaffolding, declare the splash screen in `wefter.config.json` and run `wefter sync`:

```json
{
  "splash": {
    "source": "splash",
    "minDuration": 400,
    "maxDuration": 5000,
    "dismissOn": "ready",
    "transition": "fade"
  }
}
```

```bash
wefter sync
```

## Lifecycle Hooks

`wefter splash generate` does **not** trigger CLI lifecycle hooks.

## Failure Modes & Error Resolution

| Error Message                                                         | Root Cause                            | Actionable Resolution                                           |
| --------------------------------------------------------------------- | ------------------------------------- | --------------------------------------------------------------- |
| `<path> already exists — remove it first or choose a different path.` | Target folder already exists on disk. | Pass a different `targetPath` or remove/rename existing folder. |
