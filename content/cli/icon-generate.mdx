---
title: wefter icon generate
description: Generates high-density Android launcher icons (legacy and adaptive) directly from a source image.
---

## Synopsis

```bash
wefter icon generate <source> [projectDir]
```

## Overview & Use Cases

`wefter icon generate` is a utility command that processes a high-resolution source image (at least 1024x1024px) and generates Android launcher icons across all standard density buckets.

It generates both legacy PNG launcher icons (`ic_launcher.png`) and Android 8.0+ adaptive icons (`ic_launcher_foreground.png` and `ic_launcher.xml`).

### Primary Use Cases

- Previewing Android app launcher icons directly on a device without modifying `wefter.config.json`.
- Testing custom icon source images during early UI design iteration.

<Callout type="warn">
  **Transient Preview Note**: `wefter icon generate` writes directly to the current `.wefter/native/android` project
  tree. Because [`wefter sync`](/cli/sync) regenerates native shells, icons generated by this standalone command will be
  **lost on the next `wefter sync`** unless `"icon": "./path/to/icon.png"` is set in `wefter.config.json`.
</Callout>

---

## What It Does

When invoked, `wefter icon generate` executes the following sequence:

1. **Source Image Validation**: Verifies `<source>` exists and measures image dimensions using `sharp`. Throws an error if image width/height is less than 1024x1024px.
2. **Color Palette Sampling**: Samples background colors from the source image corners to generate adaptive icon background colors (`values/colors.xml`).
3. **Density Resizing**: Generates legacy and adaptive launcher PNG files across five density buckets:
   - `mdpi` (48x48px legacy, 108x108px adaptive)
   - `hdpi` (72x72px legacy, 162x162px adaptive)
   - `xhdpi` (96x96px legacy, 216x216px adaptive)
   - `xxhdpi` (144x144px legacy, 324x324px adaptive)
   - `xxxhdpi` (192x192px legacy, 432x432px adaptive)
4. **Adaptive XML Generation**: Writes Android v26+ adaptive icon XML definitions (`mipmap-anydpi-v26/ic_launcher.xml`).

<Callout type="info">
  **Android Only**: `wefter icon generate` targets Android native projects. To generate icons for **both** iOS and
  Android permanently, set `"icon": "src/assets/icon.png"` in `wefter.config.json` and run `wefter sync`.
</Callout>

## Arguments & Options

### Arguments

| Argument     | Type       | Required / Optional | Description                                                                                 | Default                                     |
| ------------ | ---------- | ------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------- |
| `<source>`   | Positional | **Required**        | Path to source image file (relative to `projectDir`). Must be PNG/JPG, minimum 1024x1024px. | None (must be specified)                    |
| `projectDir` | Positional | Optional            | Path to project root directory.                                                             | Current working directory (`process.cwd()`) |

### Options (Flags)

`wefter icon generate` does not accept flags.

---

## Usage Examples

### Generate Android Launcher Icons from PNG

```bash
wefter icon generate ./assets/app-icon.png
```

### Generate Icons in a Specific Workspace Folder

```bash
wefter icon generate ./resources/logo.png ./apps/mobile-app
```

## Output Densities Reference

| Mipmap Density   | Legacy Icon Size | Adaptive Foreground Size |
| ---------------- | ---------------- | ------------------------ |
| `mipmap-mdpi`    | 48 x 48 px       | 108 x 108 px             |
| `mipmap-hdpi`    | 72 x 72 px       | 162 x 162 px             |
| `mipmap-xhdpi`   | 96 x 96 px       | 216 x 216 px             |
| `mipmap-xxhdpi`  | 144 x 144 px     | 324 x 324 px             |
| `mipmap-xxxhdpi` | 192 x 192 px     | 432 x 432 px             |

## Execution Output & Log Indicators

```text
[SUCCESS] Icons generated.

```

---

## Lifecycle Hooks

`wefter icon generate` does **not** trigger CLI lifecycle hooks.

---

## Failure Modes & Error Resolution

| Error Message                                                | Root Cause                                                            | Actionable Resolution                                               |
| ------------------------------------------------------------ | --------------------------------------------------------------------- | ------------------------------------------------------------------- |
| `Icon source not found: ...`                                 | File path specified by `<source>` argument does not exist.            | Verify file path spelling and ensure image file exists.             |
| `Icon source is 512x512px, but must be at least 1024x1024px` | Source image resolution is below the 1024x1024px minimum requirement. | Provide a higher resolution source image (minimum 1024x1024px PNG). |
