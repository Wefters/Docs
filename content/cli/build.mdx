---
title: wefter build
description: Compiles native Android APK binaries or iOS Simulator .app artifacts using official Gradle and Xcode toolchains.
---

## Synopsis

```bash
wefter build <platform> [--release] [--env <name>] [--simulator <name>] [projectDir]
```

## Overview & Use Cases

`wefter build` orchestrates the official native platform toolchains (`./gradlew` for Android and `xcodebuild` for iOS) to compile your synced native project into a binary artifact.

It does **not** re-sync native files or modify native bridge code. It verifies that your project has been synced recently, runs release security lints (if `--release` is passed), and invokes native toolchain compilation.

### Primary Use Cases

- Generating a Debug or Release APK for Android testing/distribution.
- Compiling an iOS Simulator `.app` bundle for iOS testing.
- Running CI/CD build scripts to produce compiled native application artifacts.

---

## What It Does

When invoked, `wefter build` executes the following sequence:

1. **Platform Validation**: Validates that `<platform>` is set to either `android` or `ios`.
2. **Sync Freshness Check**: Verifies `.wefter/sync.marker` matches the current `wefter.config.json` hash. Refuses to build if the project has never been synced or if `wefter.config.json` was modified after the last sync.
3. **Lifecycle Hook (`wefter:build:before`)**: Fires `wefter:build:before` script if declared in `package.json`.
4. **Release Security Lints**: If `--release` is passed, runs security lints (`checkReleaseSecurity` for Android, `checkReleaseSecurityIos` for iOS) to ensure debug flags are disabled and signing parameters are configured.
5. **iOS Permission Keys Check**: For iOS builds, verifies that required `Info.plist` usage description strings are present for all installed plugins.
6. **Native Compilation**:
   - **Android**: Invokes `./gradlew assemble<Env><Debug|Release>` inside `.wefter/native/android`.
   - **iOS**: Invokes `xcodebuild` targeting the iOS Simulator inside `.wefter/native/ios`.
7. **Lifecycle Hook (`wefter:build:after`)**: Fires `wefter:build:after` script once the output binary exists on disk.

## Arguments & Options

### Arguments

| Argument     | Type       | Required / Optional | Description                                 | Default                                     |
| ------------ | ---------- | ------------------- | ------------------------------------------- | ------------------------------------------- |
| `<platform>` | Positional | **Required**        | Target native platform: `android` or `ios`. | None (must be specified)                    |
| `projectDir` | Positional | Optional            | Path to project root directory.             | Current working directory (`process.cwd()`) |

### Options (Flags)

| Flag                 | Type    | Description                                                                 | Default                 |
| -------------------- | ------- | --------------------------------------------------------------------------- | ----------------------- |
| `--release`          | Boolean | Builds a release artifact instead of a debug build.                         | `false` (debug build)   |
| `--env <name>`       | String  | Environment to build against (from `environments` in `wefter.config.json`). | `"development"`         |
| `--simulator <name>` | String  | **iOS only**: `xcrun simctl` device name or UDID to build for.              | Xcode default simulator |

## Usage Examples

### Debug Android Build

```bash
wefter build android
```

### Release Android APK for Production Environment

```bash
wefter build android --release --env production
```

### iOS Simulator Build for Staging Environment

```bash
wefter build ios --env staging --simulator "iPhone 15 Pro"
```

## Output Artifact Locations

Compiled artifacts are output to the following filesystem locations:

| Platform | Build Type | Output File Location                                                          |
| -------- | ---------- | ----------------------------------------------------------------------------- |
| Android  | Debug      | `.wefter/native/android/app/build/outputs/apk/<env>/debug/*.apk`              |
| Android  | Release    | `.wefter/native/android/app/build/outputs/apk/<env>/release/*.apk`            |
| iOS      | Debug      | `.wefter/native/ios/build/Build/Products/Debug-<Env>-iphonesimulator/*.app`   |
| iOS      | Release    | `.wefter/native/ios/build/Build/Products/Release-<Env>-iphonesimulator/*.app` |

## Lifecycle Hooks

`wefter build` supports the following lifecycle hooks declared in your `package.json`:

- **`wefter:build:before`**: Fires after sync freshness check, prior to native compilation.
- **`wefter:build:after`**: Fires after native compilation succeeds and the output artifact exists on disk.

## Failure Modes & Error Resolution

| Error Message                                               | Root Cause                                                                  | Actionable Resolution                                                 |
| ----------------------------------------------------------- | --------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| `Unsupported platform "..."`                                | Platform argument was not `android` or `ios`.                               | Run `wefter build android` or `wefter build ios`.                     |
| `Project has never been synced. Run wefter sync first.`     | Project missing `.wefter/sync.marker`.                                      | Run `wefter sync` before building.                                    |
| `wefter.config.json has changed since the last wefter sync` | Configuration modified after sync.                                          | Run `wefter sync` to refresh native project files.                    |
| `Gradle build failed with exit code 1`                      | Android Gradle build error (compilation, missing dependency, syntax error). | Review Gradle error output printed above the failure message.         |
| `xcodebuild failed with exit code 65`                       | Xcode compilation or signing failure.                                       | Run `wefter doctor --release-readiness` to verify iOS signing config. |
