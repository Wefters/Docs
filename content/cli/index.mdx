# `@wefterjs/cli`

The `@wefterjs/cli` package provides the `wefter` binary executable. It reads `wefter.config.json`, resolves native plugins, generates Kotlin/Swift native project shells, and drives cross-platform build, run, and sync workflows.

```bash
npx wefter <command> [options]
```

---

## CLI Command Matrix

| Command                                          | Summary Description                                                                             | Supported Platforms |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------- | ------------------- |
| [`wefter init`](/cli/init)                       | Wraps an existing JS/TS project, writes `wefter.config.json`, and updates `package.json`.       | Cross-platform      |
| [`wefter doctor`](/cli/doctor)                   | Audits Node.js version, JDK, Android SDK/ADB, and macOS/Xcode toolchains.                       | Android & iOS       |
| [`wefter sync`](/cli/sync)                       | Resolves declared plugins and regenerates Android and iOS native project shells.                | Android & iOS       |
| [`wefter build`](/cli/build)                     | Compiles native Android APK binaries or iOS Simulator `.app` bundles via Gradle / Xcode.        | Android & iOS       |
| [`wefter run`](/cli/run)                         | Compiles, deploys, and launches app binaries with optional Vite hot reload (`--watch`).         | Android & iOS       |
| [`wefter add`](/cli/add)                         | Installs an npm plugin package, validates native code integrity, and declares it in config.     | Cross-platform      |
| [`wefter audit`](/cli/audit)                     | Read-only inspection of declared plugins, permissions, Gradle dependencies, and lockfile drift. | Android & iOS       |
| [`wefter icon generate`](/cli/icon-generate)     | Generates Android legacy and adaptive launcher icons from a high-res source image.              | Android             |
| [`wefter splash generate`](/cli/splash-generate) | Scaffolds a starter HTML/CSS splash screen template folder.                                     | Cross-platform      |
| [`wefter create-plugin`](/cli/create-plugin)     | Scaffolds cross-platform Kotlin (Android) and Swift (iOS) native plugin boilerplate.            | Android & iOS       |
| [`wefter plugin validate`](/cli/plugin-validate) | Validates plugin directory structure, method signatures, and manifest declarations.             | Cross-platform      |
| [`wefter eject`](/cli/eject)                     | Transfers full ownership of generated `android/` and `ios/` native folders to project root.     | Android & iOS       |

## Standard Development Flow

```bash
# 1. Initialize Wefter configuration in your web project
npx wefter init

# 2. Audit local machine prerequisites
npx wefter doctor

# 3. Add a native capability plugin
npx wefter add @wefterjs/camera

# 4. Weave configuration & plugins into native shells
npx wefter sync

# 5. Launch app with live hot reload
npx wefter run android --watch
# or: npx wefter run ios --watch
```
