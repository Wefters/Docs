## Synopsis

```bash
wefter sync [projectDir] [--update-lock]
```

## Overview & Use Cases

`wefter sync` is the central engine of the Wefter framework. It reads `wefter.config.json`, resolves declared native plugins from `node_modules`, copies the template native shells, and weaves Kotlin/Swift source files, Gradle/SPM dependencies, permissions, and web assets into `.wefter/native/android` and `.wefter/native/ios`.

`sync` does **not** invoke Gradle or `xcodebuild` compilation, nor does it generate an APK or `.app` binary. Native toolchain compilation is performed separately by [`wefter build`](/cli/build) or [`wefter run`](/cli/run).

### Primary Use Cases

- Applying changes made to `wefter.config.json` (environments, app branding, web output directory).
- Weaving newly installed native plugins into native Android and iOS project files after running `wefter add`.
- Refreshing generated plugin registries (`WefterPluginRegistry.kt` and `WefterPluginRegistry.swift`) and updating `wefter.lock.json`.

<Callout type="warn">
  **Sync Freshness Requirement**: `wefter build` and `wefter run` verify a sync freshness marker written by `wefter
  sync`. If `wefter.config.json` has been modified since the last sync, `build` and `run` will refuse to execute until
  you run `wefter sync`.
</Callout>

## What It Does

When executed, `wefter sync` runs through a 15-step pipeline:

1. **Lifecycle Hook (`wefter:sync:before`)**: Fires before config validation or file operations begin.
2. **Plugin Resolution**: Reads `config.plugins` from `wefter.config.json` and resolves plugin packages from `node_modules`.
3. **Permission Audit**: Scans Android plugin Kotlin sources for sensitive APIs (`CameraX`, `LocationManager`) and ensures matching Android permissions are declared in `plugin.json`.
4. **Lockfile Verification**: Compares installed plugin versions against `wefter.lock.json` and checks for version drift (unless `--update-lock` is passed).
5. **Plugin Validation**: Runs structural and signature validations on all resolved plugin directories (`validatePluginDirectory`).
6. **Native Shell Copy**: Re-creates native project shells in `.wefter/native/android` and `.wefter/native/ios` from template shells (preserving build cache directories `.gradle` and `build`).
7. **Namespace Rewriting**: Injects your application's Android namespace into `build.gradle.kts` and updates Kotlin package import declarations.
8. **Web Assets Bundling**: Copies compiled web assets from `config.webDir` into Android assets (`app/src/main/assets/public`) and iOS public bundle resources.
9. **Native Plugin Source Weaving**: Copies Kotlin (`.kt`) and Swift (`.swift`) source files from installed npm plugin packages into the native project trees.
10. **Dependency & Manifest Merging**:
    - Merges Gradle dependencies (`build.gradle.kts`) and SPM packages (`Package.swift`).
    - Merges `AndroidManifest.xml` permissions, activities, intent-filters, and ProGuard rules (`proguard-rules.pro`).
    - Merges iOS `Info.plist` usage description keys.
11. **Environment Configuration**: Injects per-environment product flavors (`build.gradle.kts`) and iOS xcconfig files (`Environment-<env>.xcconfig`).
12. **Icon & Splash Generation**: Generates native launcher icons and splash screens if `config.icon` or `config.splash` are defined.
13. **Bridge Registry Generation**: Writes `WefterPluginRegistry.kt` and `WefterPluginRegistry.swift` containing registration code for all native plugin methods.
14. **Lockfile Update (`wefter.lock.json`)**: Writes updated plugin version numbers and integrity hashes.
15. **Sync Freshness Marker & Hook (`wefter:sync:after`)**: Writes `.wefter/sync.marker` and executes `wefter:sync:after` lifecycle hook.

## Arguments & Options

### Arguments

| Argument     | Type       | Required / Optional | Description                                                     | Default                                     |
| ------------ | ---------- | ------------------- | --------------------------------------------------------------- | ------------------------------------------- |
| `projectDir` | Positional | Optional            | Path to project root directory containing `wefter.config.json`. | Current working directory (`process.cwd()`) |

### Options (Flags)

| Flag            | Type    | Description                                                                                                    | Default |
| --------------- | ------- | -------------------------------------------------------------------------------------------------------------- | ------- |
| `--update-lock` | Boolean | Accepts plugin version drift against `wefter.lock.json` and updates the lockfile instead of throwing an error. | `false` |

## Usage Examples

### Standard Sync

```bash
wefter sync
```

### Syncing with Lockfile Update

```bash
wefter sync --update-lock
```

### Syncing a Specific Workspace Directory

```bash
wefter sync ./apps/mobile
```

## Execution Output & Log Indicators

```text
[SUCCESS] Synced 2 plugin(s): @wefterjs/camera, @wefterjs/device
[INFO] Run `wefter build android` or `wefter run android` to compile.
```

If plugins declare exported Android components or contain Gradle dependency version conflicts, warnings are logged:

```text
[WARN] Exported components woven into AndroidManifest.xml (reachable from outside the app):
  - @wefterjs/camera: activity dev.wefter.plugins.camera.CameraActivity
[WARN] Gradle dependency version conflicts:
  - com.google.android.gms:play-services-location (plugin A asked for 21.0.1, plugin B asked for 21.1.0 — using 21.1.0)
```

## Lifecycle Hooks

`wefter sync` supports the following lifecycle hooks declared in your `package.json`:

- **`wefter:sync:before`**: Fires immediately when `wefter sync` starts.
- **`wefter:sync:after`**: Fires after all native files, registries, lockfiles, and sync markers have been written.

## Failure Modes & Error Resolution

| Error Message                                            | Root Cause                                                                                          | Actionable Resolution                                                                          |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `wefter.config.json not found`                           | Command run outside a Wefter project directory.                                                     | Run `wefter init` or `cd` into your project directory.                                         |
| `Plugin permission audit failed: ...`                    | A plugin uses native APIs (e.g. `CameraX`) without declaring required permissions in `plugin.json`. | Add missing permission to plugin's `plugin.json` file.                                         |
| `Plugin version drift detected against wefter.lock.json` | Plugin version in `package.json` differs from `wefter.lock.json`.                                   | Run `wefter sync --update-lock` to accept the updated plugin version.                          |
| `Web asset directory "dist" does not exist`              | `config.webDir` does not exist or has not been built yet.                                           | Run your web build script (e.g. `npm run build` or `vite build`) to produce the output folder. |
