## Synopsis

```bash
wefter doctor [--release-readiness] [projectDir]
```

## Overview & Use Cases

`wefter doctor` checks your local machine and project environment to verify that all prerequisites for building and running Wefter native applications are properly configured.

Instead of waiting for a complex Gradle compilation or `xcodebuild` invocation to fail 5 minutes into a build, `wefter doctor` runs non-destructive diagnostic checks in seconds and prints exact actionable fix instructions for any failing component.

### Primary Use Cases

- Verifying local environment setup after installing Wefter.
- Debugging missing SDKs, environment variables (`ANDROID_HOME`), or JDK versions.
- Auditing release-signing configuration prior to creating production release artifacts (`--release-readiness`).

---

## What It Checks

All checks execute regardless of earlier failures. Diagnostic results are aggregated and printed together at the end.

### Core System Checks (Both Platforms)

- **Node.js Version**: Verifies Node 18+ is running.
- **Config Schema**: Validates `wefter.config.json` schema if present in `projectDir`.

### Android Environment Checks

- **`ANDROID_HOME` / `ANDROID_SDK_ROOT`**: Verifies Android SDK path is set.
- **`adb` Executable**: Verifies `adb` is available on system `PATH`.
- **JDK 17**: Verifies Java Development Kit version (JDK 17 is required for Gradle).
- **Connected Devices / Emulators**: Checks for active ADB devices or running emulators.

### iOS Environment Checks (macOS)

- **macOS Host OS**: Verifies system is running macOS.
- **Xcode Installation**: Verifies Xcode is installed via `xcodebuild -version`.
- **Command Line Tools**: Verifies Xcode command line tools path (`xcode-select -p`).
- **iOS Simulator Devices**: Checks for available iOS simulators (`xcrun simctl list devices`).

## Arguments & Options

### Arguments

| Argument     | Type       | Required / Optional | Description                                                                  | Default                                     |
| ------------ | ---------- | ------------------- | ---------------------------------------------------------------------------- | ------------------------------------------- |
| `projectDir` | Positional | Optional            | Path to project root directory. Required when running `--release-readiness`. | Current working directory (`process.cwd()`) |

### Options (Flags)

| Flag                  | Type    | Description                                                                             | Default |
| --------------------- | ------- | --------------------------------------------------------------------------------------- | ------- |
| `--release-readiness` | Boolean | Includes additional release-signing keystore and iOS provisioning profile verification. | `false` |

---

## `--release-readiness` Checks

When `--release-readiness` is enabled, `wefter doctor` performs additional release security checks for production builds:

- **Android Keystore Configuration**: Verifies `signing` configuration in `wefter.config.json` (`keystorePath`, `keyAlias`) and confirms the keystore file exists on disk and `WEFTER_KEYSTORE_PASSWORD` environment variable is defined.
- **iOS Signing Configuration**: Verifies `iosSigning` configuration in `wefter.config.json` (`teamId`) and confirms `WEFTER_IOS_SIGNING_IDENTITY` environment variable is set.


## Lifecycle Hooks

`wefter doctor` does **not** trigger CLI lifecycle hooks.

## Failure Modes & Error Resolution

| Check Failure                                | Root Cause                                                                              | Actionable Resolution                                                                                                       |
| -------------------------------------------- | --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `ANDROID_HOME set`                           | `ANDROID_HOME` or `ANDROID_SDK_ROOT` environment variable is not defined.               | Set `export ANDROID_HOME=$HOME/Android/Sdk` in your shell profile (`~/.zshrc` or `~/.bashrc`).                              |
| `adb on PATH`                                | `adb` binary cannot be found in `$PATH`.                                                | Add `$ANDROID_HOME/platform-tools` to your `$PATH`.                                                                         |
| `JDK version`                                | System Java version is not JDK 17.                                                      | Install JDK 17 (e.g. `brew install openjdk@17`) and set `JAVA_HOME`.                                                        |
| `Connected device or running emulator`       | No active Android device or emulator detected.                                          | Launch an Android Virtual Device (AVD) from Android Studio or connect a physical device via USB with USB Debugging enabled. |
| `Running on macOS`                           | Command executed on Linux or Windows.                                                   | iOS builds require macOS. For Android-only development on Linux/Windows, disregard iOS-specific warnings.                   |
| `Xcode installed`                            | Xcode application is not installed on macOS.                                            | Install Xcode from the Mac App Store.                                                                                       |
| `Signing config` (`--release-readiness`)     | Android release keystore missing or `WEFTER_KEYSTORE_PASSWORD` unset.                   | Define `signing` block in `wefter.config.json` and export `WEFTER_KEYSTORE_PASSWORD`.                                       |
| `iOS signing config` (`--release-readiness`) | `iosSigning` block missing or `WEFTER_IOS_SIGNING_IDENTITY` environment variable unset. | Define `iosSigning.teamId` in `wefter.config.json` and export `WEFTER_IOS_SIGNING_IDENTITY`.                                |
