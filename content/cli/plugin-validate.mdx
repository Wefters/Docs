## Synopsis

```bash
wefter plugin validate [pluginDir]
```

## Overview & Use Cases

`wefter plugin validate` validates a Wefter native plugin package directory to ensure it conforms to Wefter plugin schema rules, native method annotations, and permission handling requirements.

It runs the exact same validation engine used by [`wefter add`](/cli/add) and [`wefter sync`](/cli/sync), allowing plugin authors to verify their plugin implementation locally without needing a host application.

### Primary Use Cases

- Verifying custom plugin code during development before publishing or linking.
- Running CI validation checks on open-source or internal plugin repositories.
- Debugging method signature mismatches between `plugin.json` and Kotlin/Swift native source files.

---

## What It Checks

When executed, `wefter plugin validate` runs a 7-step inspection suite:

1. **`plugin.json` Presence**: Verifies `plugin.json` exists in `pluginDir`.
2. **`plugin.json` Schema Validation**: Verifies `name`, `permissions`, `nativeDependencies`, `methods`, `hooks`, and `events` conform to the Wefter plugin schema.
3. **Native Directory Check**: Verifies that at least one native source directory (`android/` or `ios/`) exists.
4. **Signature Formatting Audit**: Concatenates `.kt` (Android) and `.swift` (iOS) source files and audits every `@WefterMethod` and `@WefterHook` for correct parameter types:
   - **Kotlin**: `@WefterMethod fun name(payload: JSONObject, callback: (Result<Any>) -> Unit)`
   - **Swift**: `// @WefterMethod func name(payload: [String: Any], callback: @escaping (Result<Any, Error>) -> Void) throws`
5. **Android Manifest & Gradle Coordinate Checks**:
   - Verifies class references declared in `android.manifestEntries` resolve to actual `class` or `object` definitions in Kotlin source.
   - Validates `nativeDependencies.android.gradle` strings conform to Maven coordinate format (`group:artifact:version`).
6. **Method & Hook Consistency Audit**: Cross-checks methods/hooks declared in `plugin.json` against methods/hooks annotated in native source files across all supported platforms.
7. **Dangerous Permission Handler Check (Android)**: If `plugin.json` declares dangerous Android permissions (camera, location, contacts, etc.), verifies that Kotlin source includes `PERMISSION_DENIED` handling code.

## Arguments & Options

### Arguments

| Argument    | Type       | Required / Optional | Description                                                | Default                                     |
| ----------- | ---------- | ------------------- | ---------------------------------------------------------- | ------------------------------------------- |
| `pluginDir` | Positional | Optional            | Path to plugin package directory containing `plugin.json`. | Current working directory (`process.cwd()`) |

### Options (Flags)

`wefter plugin validate` does not accept flags.

---

## Usage Examples

### Validate Plugin in Current Directory

```bash
wefter plugin validate
```

### Validate Plugin in a Specific Directory Path

```bash
wefter plugin validate ./plugins/secure-storage
```

---

## Execution Output & Log Indicators

### Success Output

```text
[SUCCESS] Plugin is valid.
```

### Failure Output

```text
[ERROR] Plugin validation failed:
  - Plugin "secure-storage": plugin.json's "methods" declares [store, retrieve] but source has [store]. Missing: [retrieve].
  - Malformed Gradle coordinate "camera-core" in nativeDependencies.android.gradle — expected "group:artifact:version".
```

---

## Lifecycle Hooks

`wefter plugin validate` does **not** trigger CLI lifecycle hooks.

---

## Failure Modes & Error Resolution

| Error Message                                                                                                 | Root Cause                                                                                  | Actionable Resolution                                                                               |
| ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `No plugin.json found — not a Wefter plugin.`                                                                 | `plugin.json` is missing in `pluginDir`.                                                    | Run `wefter create-plugin` or create a valid `plugin.json` file.                                    |
| `Invalid plugin.json: ...`                                                                                    | Schema validation error in `plugin.json`.                                                   | Fix property types or formatting errors in `plugin.json`.                                           |
| `No android/ or ios/ directory found`                                                                         | Plugin package is missing both `android/` and `ios/` native source folders.                 | Create an `android/` or `ios/` folder containing native plugin source code.                         |
| `Malformed @WefterMethod signature at line <n>`                                                               | Kotlin or Swift method signature does not match expected parameter types.                   | Ensure method accepts `JSONObject` (Android) or `[String: Any]` (iOS) and a callback function.      |
| `plugin.json's "methods" declares [...] but source has [...]`                                                 | Discrepancy between methods declared in `plugin.json` and methods annotated in native code. | Update `methods` array in `plugin.json` to match native method definitions.                         |
| `Plugin "<name>" declares dangerous Android permission(s) ... but no method rejects with "PERMISSION_DENIED"` | Android Kotlin source uses dangerous permissions without explicit rejection handling.       | Include permission denial handling logic returning `PERMISSION_DENIED` error code in Kotlin source. |
