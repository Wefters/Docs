## Fields

| Field | Type | Default | Purpose |
| --- | --- | --- | --- |
| `webDir` | `string` | `"dist"` | Where your built web app lives; copied into every configured platform's native assets on every `sync`. |
| `plugins` | `string[]` | `[]` | Explicit list of plugin package names to weave in. See [Plugin Registry](/docs/plugin-registry), nothing outside this array is ever included. |
| `pluginsDir` | `string` | `"node_modules"` | Where declared plugin packages are resolved from. |
| `environments` | `Record<string, Environment>` | `{ development: {...} }` | Named build environments (see below). |
| `icon` | `string` (optional) | — | Path to a source icon image. See [App Icon](/docs/app-icon). |
| `splash` | `false \| SplashConfig` (optional) | — (disabled) | Splash screen config. See [App Splash Screen](/docs/app-splash-screen). |
| `signing` | `SigningConfig` (optional) | — | Android release signing config (see below). |
| `iosSigning` | `IosSigningConfig` (optional) | — | iOS signing config (see below). |

### `environments.<name>`

| Field | Type | Purpose |
| --- | --- | --- |
| `appId` | `string` | Android application ID (e.g. `com.yourcompany.app`). Must match `^[a-z][a-z0-9_]*(\.[a-z][a-z0-9_]*)+$`. Also used as the iOS bundle identifier by default. |
| `appName` | `string` | Display name shown on the device, both platforms. |
| `iosBundleId` | `string` (optional) | Overrides `appId` for iOS specifically. Only needed if your team already has a different registered App Store bundle ID than your Android application ID; otherwise omit it and `appId` is reused for both. |

Referenced via `--env` on `wefter build`/`wefter run` (defaults to `development`).

### `splash`

| Field | Type | Default | Purpose |
| --- | --- | --- | --- |
| `html` | `string` | — (required when splash is enabled) | Path to your splash HTML file. Same file, both platforms. |
| `minDurationMs` | `number` (0–5000) | `600` | Minimum time the splash stays up, even if the app is ready sooner. |
| `fadeOutDurationMs` | `number` (0–1000) | `300` | Fade-out transition length. |

`splash: false` and omitting the key entirely are identical, both mean no
splash at all, on either platform. Full detail on
[App Splash Screen](/docs/app-splash-screen).

### `signing` (Android)

| Field | Type | Purpose |
| --- | --- | --- |
| `keystorePath` | `string` | Path to your release keystore file. |
| `keyAlias` | `string` | Key alias within that keystore. |

The keystore password is not stored in config; set `WEFTER_KEYSTORE_PASSWORD`
in a gitignored `.env` file instead. `wefter doctor --release-readiness`
checks for a `signing` block, that the keystore file actually exists at
`keystorePath`, and that `WEFTER_KEYSTORE_PASSWORD` is set, before you
attempt a `--release` build for Android.

### `iosSigning`

| Field | Type | Purpose |
| --- | --- | --- |
| `teamId` | `string` | Your Apple Developer Team ID. |
| `provisioningProfile` | `string` (optional) | A specific provisioning profile name. Omit for automatic signing. |

The signing identity itself is not stored in config; set
`WEFTER_IOS_SIGNING_IDENTITY`, `WEFTER_IOS_TEAM_ID`, and
`WEFTER_IOS_PROVISIONING_PROFILE` in a gitignored `.env` file. `wefter
doctor --release-readiness` checks these the same way it checks Android's
signing config, before you attempt a `--release` build for iOS.

## Full example

```json
{
  "webDir": "dist",
  "environments": {
    "development": { "appId": "com.yourcompany.app.dev", "appName": "Your App (Dev)" },
    "production": { "appId": "com.yourcompany.app", "appName": "Your App" }
  },
  "icon": "./resources/icon.png",
  "splash": {
    "html": "./resources/splash.html",
    "minDurationMs": 1200,
    "fadeOutDurationMs": 400
  },
  "signing": {
    "keystorePath": "./release.keystore",
    "keyAlias": "release"
  },
  "iosSigning": {
    "teamId": "ABCDE12345"
  },
  "plugins": ["@wefter/plugin-device-info"]
}
```
