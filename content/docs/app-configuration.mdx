## Overview

The `wefter.config.json` manifest file resides at the root of a Wefter web application.

It specifies web build directories, declared native plugins, environment variables, splash screen options, icon paths, and native release signing credentials.

---

## Complete `wefter.config.json` Schema Reference

| Property           | Type                          | Required / Optional | Default                  | Description                                                                              |
| ------------------ | ----------------------------- | ------------------- | ------------------------ | ---------------------------------------------------------------------------------------- |
| `webDir`           | String                        | **Required**        | `"dist"`                 | Path to compiled web assets folder. Copied to native asset folders during `wefter sync`. |
| `plugins`          | Array of Strings              | Optional            | `[]`                     | Explicit array of plugin package names to weave into native shells.                      |
| `pluginsDir`       | String                        | Optional            | `"node_modules"`         | Root folder where declared plugin packages are resolved from.                            |
| `pluginConfig`     | `Record<string, string>`      | Optional            | `{}`                     | Key-value store resolved by plugin `android.manifestEntries` placeholders (`${key}`).    |
| `environments`     | `Record<string, Environment>` | **Required**        | `{ development: {...} }` | Dictionary of named build environment configurations.                                    |
| `icon`             | String                        | Optional            | None                     | Path to source icon PNG image (minimum 1024x1024px).                                     |
| `splash`           | Boolean or Object             | Optional            | `false`                  | Splash screen configuration object (or `false` to disable).                              |
| `launchBackground` | String                        | Optional            | Sampled / `#FFFFFF`      | 6-digit hex background color (`#RRGGBB`) rendered natively during OS launch.             |
| `signing`          | Object                        | Optional            | None                     | Android release keystore signing configuration.                                          |
| `iosSigning`       | Object                        | Optional            | None                     | iOS Apple Developer signing configuration.                                               |

---

## Environment Configuration (`environments.<name>`)

| Property      | Type   | Required / Optional | Description                                                              |
| ------------- | ------ | ------------------- | ------------------------------------------------------------------------ |
| `appId`       | String | **Required**        | Reverse-DNS Android application ID (e.g. `com.company.myapp`).           |
| `appName`     | String | **Required**        | Display application name shown under device launcher icons.              |
| `iosBundleId` | String | Optional            | Overrides `appId` for iOS specifically (if App Store bundle ID differs). |

```json
{
  "environments": {
    "development": {
      "appId": "dev.local.myapp",
      "appName": "My App (Dev)"
    },
    "production": {
      "appId": "com.company.myapp",
      "appName": "My App"
    }
  }
}
```

## Splash Screen Configuration (`splash`)

| Property      | Type        | Default      | Description                                                           |
| ------------- | ----------- | ------------ | --------------------------------------------------------------------- |
| `source`      | String      | **Required** | Path to custom HTML splash screen folder containing `index.html`.     |
| `minDuration` | Number (ms) | `0`          | Minimum display duration in milliseconds (0-20,000ms).                |
| `maxDuration` | Number (ms) | `5000`       | Hard cap maximum display duration in milliseconds (0-20,000ms).       |
| `dismissOn`   | String      | `"ready"`    | Dismissal trigger: `"ready"` (waits for `hideSplash()`) or `"timer"`. |
| `transition`  | String      | `"fade"`     | Dismissal animation: `"fade"` or `"none"`.                            |

```json
{
  "splash": {
    "source": "./resources/splash",
    "minDuration": 400,
    "maxDuration": 5000,
    "dismissOn": "ready",
    "transition": "fade"
  }
}
```

## Release Signing Configuration

### Android Signing (`signing`)

| Property       | Type   | Description                                          |
| -------------- | ------ | ---------------------------------------------------- |
| `keystorePath` | String | Relative path to release `.keystore` or `.jks` file. |
| `keyAlias`     | String | Key alias within the keystore file.                  |

<Callout type="info">
  **Keystore Password**: Store your keystore password in `.env` as `WEFTER_KEYSTORE_PASSWORD=your_password` rather than
  hardcoding it in `wefter.config.json`.
</Callout>

### iOS Signing (`iosSigning`)

| Property              | Type   | Description                                                      |
| --------------------- | ------ | ---------------------------------------------------------------- |
| `teamId`              | String | 10-character Apple Developer Team ID.                            |
| `provisioningProfile` | String | Optional provisioning profile name (omit for automatic signing). |

## Complete `wefter.config.json` Example

```json
{
  "webDir": "dist",
  "environments": {
    "development": {
      "appId": "dev.local.myapp",
      "appName": "App (Dev)"
    },
    "production": {
      "appId": "com.company.myapp",
      "appName": "App"
    }
  },
  "icon": "./resources/icon.png",
  "splash": {
    "source": "./resources/splash",
    "minDuration": 400,
    "maxDuration": 5000,
    "dismissOn": "ready",
    "transition": "fade"
  },
  "launchBackground": "#14161C",
  "signing": {
    "keystorePath": "./release.keystore",
    "keyAlias": "release"
  },
  "iosSigning": {
    "teamId": "ABCDE12345"
  },
  "plugins": ["@wefterjs/camera"],
  "pluginConfig": {
    "appScheme": "myapp"
  }
}
```
