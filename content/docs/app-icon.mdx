## Overview

Wefter generates native application launcher icons for both Android and iOS from a single source PNG image specified in `wefter.config.json`.

```json
{
  "icon": "./resources/icon.png"
}
```

---

## Source Image Requirements

<Callout type="warn">
  **Minimum Image Dimensions**: The source icon image **must be at least
  1024x1024px**. `wefter sync` rejects source images smaller than 1024x1024px to
  prevent pixelated launcher icons.
</Callout>

- **Format**: PNG image.
- **Dimensions**: Square 1024x1024px (or larger).
- **Color Space**: RGBA color space.

---

## Generated Android Icon Assets

During [`wefter sync`](/cli/sync), Wefter resizes the source image into all standard Android mipmap density buckets (`ic_launcher.png` and `ic_launcher_foreground.png`):

| Android Mipmap Density | Legacy Icon Size (`ic_launcher.png`) | Adaptive Foreground Size (`ic_launcher_foreground.png`) |
| ---------------------- | ------------------------------------ | ------------------------------------------------------- |
| `mipmap-mdpi`          | 48 x 48 px                           | 108 x 108 px                                            |
| `mipmap-hdpi`          | 72 x 72 px                           | 162 x 162 px                                            |
| `mipmap-xhdpi`         | 96 x 96 px                           | 216 x 216 px                                            |
| `mipmap-xxhdpi`        | 144 x 144 px                         | 324 x 324 px                                            |
| `mipmap-xxxhdpi`       | 192 x 192 px                         | 432 x 432 px                                            |

In addition to image assets, `wefter sync` generates:

- **`mipmap-anydpi-v26/ic_launcher.xml`**: Adaptive icon definition for Android 8.0+ (API 26+).
- **`mipmap-anydpi-v26/ic_launcher_round.xml`**: Round adaptive icon definition.
- **`ic_launcher_background`**: Color resource sampled from the corner pixel of the source image.

---

## Generated iOS Icon Assets

For iOS, `wefter sync` generates `AppIcon.appiconset/icon-1024.png` (flattened on an opaque background as required by Apple) and writes `Contents.json` configured for Xcode compilation.

---

## Previewing Icons with `wefter icon generate`

To generate and preview Android icon assets standalone without modifying `wefter.config.json`, run [`wefter icon generate`](/cli/icon-generate):

```bash
wefter icon generate ./resources/icon.png
```
