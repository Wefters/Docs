## Overview

The native launch background (`launchBackground`) is the OS-level background color rendered immediately when an application icon is tapped, prior to WebView rendering.

Configuring a native launch background prevents white screen flashes during cold app starts.

---

## Configuration (`launchBackground`)

Declare `launchBackground` at the root of `wefter.config.json` as a 6-digit hex color string (`#RRGGBB`):

```json
{
  "launchBackground": "#14161C"
}
```

| Property           | Type                           | Default                                   | Description                                                     |
| ------------------ | ------------------------------ | ----------------------------------------- | --------------------------------------------------------------- |
| `launchBackground` | String (6-digit hex `#RRGGBB`) | Sampled from `splash.source` or `#FFFFFF` | OS-level background color displayed before WebViews initialize. |

---

## Automatic Color Sampling Fallback

If `launchBackground` is omitted but `splash` is configured, `wefter sync` automatically samples your splash folder's `index.html` file.

It inspects inline `<style>` tags and linked CSS stylesheets for `background` or `background-color` declarations on `body`, `:root`, or `html` rules. The first detected 6-digit hex color becomes the native launch background. If no CSS background is detected, it defaults to `#FFFFFF`.

---

## Platform Implementation Details

- **Android**: Written into `.wefter/native/android/app/src/main/res/values/colors.xml` as `<color name="splashBackground">`. Referenced by both `windowBackground` and `windowSplashScreenBackground` (Android 12+ Splash API).
- **iOS**: Converted to RGB float values (0 to 1) and written directly into `.wefter/native/ios/LaunchScreen.storyboard`'s `<color>` XML node.
