## Overview

Wefter supports custom HTML-based splash screens. Rather than compiling static static images, Wefter loads developer-authored HTML, CSS, and images inside a dedicated native WebView.

The splash screen is **disabled by default** (`splash: false`).

---

## The 2-Stage Splash Loading Model

<Steps>
  <Step>
    ### Stage 1: Native OS Launch Background Brief OS-level launch background (`androidx.core.splashscreen` on Android,
    `LaunchScreen.storyboard` on iOS) displayed before WebViews initialize.
  </Step>
  <Step>
    ### Stage 2: Custom HTML Splash Screen WebView Dedicated native WebView rendering HTML assets from your
    `splash.source` directory in parallel with main application initialization.
  </Step>
  <Step>
    ### Main Web Application Rendered Main application WebView mounts and issues `hideSplash()` call (or timer expires)
    to dismiss the Stage 2 splash screen.
  </Step>
</Steps>

### Stage 1: Native OS Launch Background

A brief, OS-level launch background (`androidx.core.splashscreen` on Android, `LaunchScreen.storyboard` on iOS) displayed before WebViews initialize to prevent white screen flashes.

### Stage 2: Custom HTML Splash Screen

A dedicated native WebView that renders HTML assets from your `splash.source` directory in parallel with main application initialization.

## Splash Folder Anatomy

Declare a folder containing an `index.html` file and relative assets:

```text
resources/splash/
├── index.html          # Entry point
├── logo.png            # Relative image asset
└── style.css           # Relative stylesheet
```

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8" />
    <link rel="stylesheet" href="./style.css" />
  </head>
  <body>
    <div class="splash-container">
      <img src="./logo.png" alt="Logo" class="splash-logo" />
    </div>
  </body>
</html>
```

## Configuration Properties (`splash`)

Enable splash screen rendering in `wefter.config.json`:

```json
{
  "splash": {
    "source": "./resources/splash",
    "minDuration": 400,
    "maxDuration": 5000,
    "dismissOn": "ready",
    "transition": "fade"
  }
}
```

| Property      | Type        | Default      | Description                                                                              |
| ------------- | ----------- | ------------ | ---------------------------------------------------------------------------------------- |
| `source`      | String      | **Required** | Relative path to splash HTML directory containing `index.html`.                          |
| `minDuration` | Number (ms) | `0`          | Minimum display duration in milliseconds (0 - 20,000ms).                                 |
| `maxDuration` | Number (ms) | `5000`       | Hard cap maximum display duration in milliseconds (0 - 20,000ms).                        |
| `dismissOn`   | String      | `"ready"`    | Trigger: `"ready"` (waits for `hideSplash()`) or `"timer"` (dismisses on `minDuration`). |
| `transition`  | String      | `"fade"`     | Animation: `"fade"` (fades out over ~200ms) or `"none"`.                                 |

---

## Dismissal Mechanics (`hideSplash()`)

When `dismissOn: "ready"` is configured, the splash WebView remains visible until your main web application invokes `hideSplash()` from `@wefterjs/core`:

```ts
import { hideSplash } from "@wefterjs/core";

// Call inside main application once initial UI component mounts
await hideSplash();
```

<Callout type="info">
  **Dismissal Safety Guarantees**: - The splash screen will never dismiss prior to `minDuration`. - The splash screen
  will automatically dismiss when `maxDuration` is reached even if `hideSplash()` is never called.
</Callout>

## Scaffolding a Splash Template

Scaffold a ready-to-use HTML/CSS splash boilerplate folder using [`wefter splash generate`](/cli/splash-generate):

```bash
wefter splash generate
```
