## Overview

The `@wefterjs/core` npm package provides client-side JavaScript APIs for communicating with native bridge dispatchers, listening to event streams, and managing application state.

---

## Core Runtime Functions Reference

| Function Signature                                    | Return Type                                        | Description                                                                                                                                                              |
| ----------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `invokeNative<T>(plugin, method, payload?, options?)` | `Promise<T>`                                       | Low-level bridge function invoking a native plugin method.                                                                                                               |
| `definePlugin<T>(pluginName, methodMap)`              | `T`                                                | Generates a typed Promise object wrapper for request/response methods.                                                                                                   |
| `registerHook(hookName, callback)`                    | `{ remove(): void }`                               | Subscribes a JS callback to native event streams (`emit`).                                                                                                               |
| `hideSplash()`                                        | `Promise<void>`                                    | Signals completion of web UI mounting to dismiss Stage 2 HTML splash screen.                                                                                             |
| `getDeviceInfo()`                                     | `Promise<{ platform: string; osVersion: string }>` | Asynchronously fetches OS platform and system version directly from native shell.                                                                                        |
| `onBridgeReady()`                                     | `Promise<void>`                                    | Resolves once native WebView bridge initialization has completed.                                                                                                        |
| `isNativeBridgeAvailable()`                           | `Boolean`                                          | Synchronously checks if JS is executing inside a Wefter native WebView.                                                                                                  |
| `getPlatformInfo()`                                   | `{ platform, coreVersion, environment }`           | Synchronously returns platform identifier, `@wefterjs/core` version, and active environment.                                                                             |
| `onDeepLink(callback)`                                | `{ remove(): void }`                               | Calls `callback` for every URL the app is opened with: the launch link and links that arrive while it runs.                                                              |
| `getLaunchUrl()`                                      | `Promise<string \| null>`                          | Returns the URL that started the app, or `null` when it was opened normally.                                                                                             |
| `openAppSettings()`                                   | `Promise<void>`                                    | Opens the app's page in the system settings, where the user can allow a permission they denied.                                                                          |
| `exposeToFrames(methods)`                             | `FrameHost`                                        | Lets sites in the page's iframes call the listed methods and exchange events. See [Embedded Sites](/docs/app-configuration/embedded-sites).                              |
| `openWebWindow(options)`                              | `Promise<WebWindow>`                               | Opens a website over the app in a web window that can talk to the app. See [Embedded Sites](/docs/app-configuration/embedded-sites#web-windows-openwebwindow).           |
| `onBack(listener)`                                    | `() => void`                                       | Handles Android's back button and gesture, and the iOS swipe back with `swipeBack: "page"`, in the page. See [Back Navigation](/docs/app-configuration/back-navigation). |
| `setSystemBars(bars)`, `getSystemBars()`              | `Promise<SystemBarsState>`                         | Hides or shows the status and navigation bars and sets their icon colour. See [System Bars & Safe Area](/docs/app-configuration/system-bars).                            |
| `getSafeArea()`, `onSafeAreaChange(listener)`         | `Promise<SafeArea>`, `() => void`                  | The insets the bars, notch and home indicator cover, in CSS pixels. See [System Bars & Safe Area](/docs/app-configuration/system-bars#the-safe-area).                    |
| `setGestures(gestures)`, `getGestures()`              | `Promise<GesturesState>`                           | Turns zoom, long press, overscroll and the iOS swipe back on or off, and protects screen edges. See [Gestures](/docs/app-configuration/gestures).                        |

## Function Details & Usage Examples

### 1. `invokeNative`

```ts
function invokeNative<T = unknown>(
  plugin: string,
  method: string,
  payload?: unknown,
  options?: { signal?: AbortSignal; timeoutMs?: number },
): Promise<T>;
```

#### Code Example with Cancellation

```ts
import { invokeNative } from "@wefterjs/core";

const controller = new AbortController();
setTimeout(() => controller.abort(), 3000);

try {
  const result = await invokeNative<{ active: boolean }>(
    "camera",
    "toggleTorch",
    { enable: true },
    { signal: controller.signal, timeoutMs: 5000 },
  );
} catch (error) {
  // Catch WefterBridgeError
}
```

---

### 2. `registerHook`

```ts
import { registerHook } from "@wefterjs/core";

const subscription = registerHook("scanner:result", (data) => {
  console.log("Scanned result:", data);
});

// Remove listener on component unmount
subscription.remove();
```

---

Events a plugin held because they happened before anyone listened (such as a notification tap that launched the app) are delivered to the first listener registered for that name, right after it registers.

### Permission states: `PermissionState`

Plugins that need permissions have `checkPermissions()` and `requestPermissions()`, which resolve to `"granted"`, `"prompt"`, `"denied"` or `"limited"` per permission (types `PermissionState` and `PermissionStatus`). For `"denied"`, only the system settings can change it:

```ts
import { openAppSettings } from "@wefterjs/core";
import { Scanner } from "@wefterjs/scanner";

const { camera } = await Scanner.checkPermissions();
if (camera === "denied") await openAppSettings();
```

### 3. `isNativeBridgeAvailable`

```ts
import { isNativeBridgeAvailable, getDeviceInfo } from "@wefterjs/core";

if (isNativeBridgeAvailable()) {
  const info = await getDeviceInfo();
  console.log(`Running natively on ${info.platform} ${info.osVersion}`);
} else {
  console.log("Running inside standard web browser tab");
}
```

### 4. Deep links: `onDeepLink` and `getLaunchUrl`

Deep links are handled by the native shell, so they work without any plugin. Register the app's URL schemes with [`deepLinks`](/docs/app-configuration/deep-links) in `wefter.config.json`. The shell keeps each incoming link until the web app takes it, so a link that opens the app before the page has loaded is not lost, and reloading the page does not deliver it twice.

```ts
import { onDeepLink } from "@wefterjs/core";

// myshop://product/42?ref=mail and https://shop.example.com/product/42 both give path "/product/42"
const subscription = onDeepLink(({ url, path, query, isLaunch }) => {
  router.push({ path, query });
});
```

| Field      | Description                                                                                  |
| ---------- | -------------------------------------------------------------------------------------------- |
| `url`      | The full URL.                                                                                |
| `scheme`   | The scheme without the colon, such as `myshop` or `https`.                                   |
| `path`     | The in-app path: the URL's path for web links, and the host plus path for custom schemes.    |
| `query`    | The query parameters. When a key repeats, the last value wins.                               |
| `isLaunch` | `true` for the link that started the app, `false` for one that arrived while it was running. |

Subscribe once, early (for example where the router is created), so the launch link reaches your handler. Treat every link as untrusted input: use it to choose a screen, never to perform an action such as a payment or a deletion on its own.

## Bridge Error Handling: `WefterBridgeError`

Rejections from `invokeNative` throw instances of `WefterBridgeError` containing a strongly-typed `.code` property:

```ts
class WefterBridgeError extends Error {
  readonly code: WefterErrorCode;
}
```

### `WefterErrorCode` Reference Table

| Code String           | Origin            | Description                                                                           | Recommended Handling                                                        |
| --------------------- | ----------------- | ------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `"TIMEOUT"`           | `@wefterjs/core`  | Call exceeded `timeoutMs` limit (default 10,000ms).                                   | Retry operation or inform user of delay.                                    |
| `"ABORTED"`           | `@wefterjs/core`  | Call was cancelled by `AbortSignal`.                                                  | Handle clean cancellation state.                                            |
| `"NO_BRIDGE"`         | `@wefterjs/core`  | Execution running outside native WebView (browser tab).                               | Check `isNativeBridgeAvailable()` or show browser fallback UI.              |
| `"UNKNOWN_PLUGIN"`    | Native Dispatcher | Plugin name is not declared in `wefter.config.json`.                                  | Add plugin via `wefter add` and run `wefter sync`.                          |
| `"INVALID_PAYLOAD"`   | Native Dispatcher | Native side failed to parse payload JSON parameters.                                  | Verify payload matches documented parameters.                               |
| `"PLUGIN_THREW"`      | Native Dispatcher | Native Kotlin or Swift code threw an unhandled exception.                             | Inspect native logs for root cause traceback.                               |
| `"PERMISSION_DENIED"` | Native Plugin     | Required Android or iOS runtime permission was denied.                                | Prompt user to grant permission in device settings.                         |
| `"FORBIDDEN_ORIGIN"`  | Native Dispatcher | The calling page's origin may not use that plugin method (another site in an iframe). | Grant it with `frames.plugins`, or expose a method with `exposeToFrames()`. |
| `"UNKNOWN_METHOD"`    | Native Plugin     | The plugin has no such method.                                                        | Check the plugin's version and method name.                                 |
| `"UNKNOWN"`           | Either            | General catch-all error code.                                                         | Inspect `error.message` for detailed diagnostics.                           |

#### Error Catch Example

```ts
import { invokeNative, WefterBridgeError } from "@wefterjs/core";

try {
  await invokeNative("camera", "open");
} catch (error) {
  if (error instanceof WefterBridgeError) {
    switch (error.code) {
      case "PERMISSION_DENIED":
        console.error("Camera permission denied");
        break;
      case "NO_BRIDGE":
        console.warn("Running in browser tab");
        break;
      default:
        console.error("Native call failed:", error.message);
    }
  }
}
```

## Unit Testing with `@wefterjs/core/testing`

Mock native bridge responses in Vitest or Jest without a physical device:

```ts
// @vitest-environment jsdom
import { afterEach, describe, expect, it } from "vitest";
import { installMockBridge, uninstallMockBridge } from "@wefterjs/core/testing";
import { getDeviceInfo } from "@wefterjs/core";

describe("Web UI Component", () => {
  afterEach(() => uninstallMockBridge());

  it("fetches mocked device information", async () => {
    installMockBridge({
      __system: (method) => {
        if (method === "getDeviceInfo") {
          return { platform: "android", osVersion: "14" };
        }
        throw new Error(`Unmocked method ${method}`);
      },
    });

    const info = await getDeviceInfo();
    expect(info.platform).toBe("android");
    expect(info.osVersion).toBe("14");
  });
});
```
