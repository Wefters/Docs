## Overview

The `@wefterjs/core` npm package provides client-side JavaScript APIs for communicating with native bridge dispatchers, listening to event streams, and managing application state.

---

## Core Runtime Functions Reference

| Function Signature                                    | Return Type                                        | Description                                                                                  |
| ----------------------------------------------------- | -------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `invokeNative<T>(plugin, method, payload?, options?)` | `Promise<T>`                                       | Low-level bridge function invoking a native plugin method.                                   |
| `definePlugin<T>(pluginName, methodMap)`              | `T`                                                | Generates a typed Promise object wrapper for request/response methods.                       |
| `registerHook(hookName, callback)`                    | `{ remove(): void }`                               | Subscribes a JS callback to native event streams (`emit`).                                   |
| `hideSplash()`                                        | `Promise<void>`                                    | Signals completion of web UI mounting to dismiss Stage 2 HTML splash screen.                 |
| `getDeviceInfo()`                                     | `Promise<{ platform: string; osVersion: string }>` | Asynchronously fetches OS platform and system version directly from native shell.            |
| `onBridgeReady()`                                     | `Promise<void>`                                    | Resolves once native WebView bridge initialization has completed.                            |
| `isNativeBridgeAvailable()`                           | `Boolean`                                          | Synchronously checks if JS is executing inside a Wefter native WebView.                      |
| `getPlatformInfo()`                                   | `{ platform, coreVersion, environment }`           | Synchronously returns platform identifier, `@wefterjs/core` version, and active environment. |

## Function Details & Usage Examples

### 1. `invokeNative`

```ts
function invokeNative<T = unknown>(
  plugin: string,
  method: string,
  payload?: unknown,
  options?: { signal?: AbortSignal; timeoutMs?: number },
): Promise<T>;
```

#### Code Example with Cancellation

```ts
import { invokeNative } from "@wefterjs/core";

const controller = new AbortController();
setTimeout(() => controller.abort(), 3000);

try {
  const result = await invokeNative<{ active: boolean }>(
    "camera",
    "toggleTorch",
    { enable: true },
    { signal: controller.signal, timeoutMs: 5000 },
  );
} catch (error) {
  // Catch WefterBridgeError
}
```

---

### 2. `registerHook`

```ts
import { registerHook } from "@wefterjs/core";

const subscription = registerHook("scanner:result", (data) => {
  console.log("Scanned result:", data);
});

// Remove listener on component unmount
subscription.remove();
```

---

### 3. `isNativeBridgeAvailable`

```ts
import { isNativeBridgeAvailable, getDeviceInfo } from "@wefterjs/core";

if (isNativeBridgeAvailable()) {
  const info = await getDeviceInfo();
  console.log(`Running natively on ${info.platform} ${info.osVersion}`);
} else {
  console.log("Running inside standard web browser tab");
}
```

## Bridge Error Handling: `WefterBridgeError`

Rejections from `invokeNative` throw instances of `WefterBridgeError` containing a strongly-typed `.code` property:

```ts
class WefterBridgeError extends Error {
  readonly code: WefterErrorCode;
}
```

### `WefterErrorCode` Reference Table

| Code String           | Origin            | Description                                               | Recommended Handling                                           |
| --------------------- | ----------------- | --------------------------------------------------------- | -------------------------------------------------------------- |
| `"TIMEOUT"`           | `@wefterjs/core`  | Call exceeded `timeoutMs` limit (default 10,000ms).       | Retry operation or inform user of delay.                       |
| `"ABORTED"`           | `@wefterjs/core`  | Call was cancelled by `AbortSignal`.                      | Handle clean cancellation state.                               |
| `"NO_BRIDGE"`         | `@wefterjs/core`  | Execution running outside native WebView (browser tab).   | Check `isNativeBridgeAvailable()` or show browser fallback UI. |
| `"UNKNOWN_PLUGIN"`    | Native Dispatcher | Plugin name is not declared in `wefter.config.json`.      | Add plugin via `wefter add` and run `wefter sync`.             |
| `"INVALID_PAYLOAD"`   | Native Dispatcher | Native side failed to parse payload JSON parameters.      | Verify payload matches documented parameters.                  |
| `"PLUGIN_THREW"`      | Native Dispatcher | Native Kotlin or Swift code threw an unhandled exception. | Inspect native logs for root cause traceback.                  |
| `"PERMISSION_DENIED"` | Native Plugin     | Required Android or iOS runtime permission was denied.    | Prompt user to grant permission in device settings.            |
| `"UNKNOWN"`           | Either            | General catch-all error code.                             | Inspect `error.message` for detailed diagnostics.              |

#### Error Catch Example

```ts
import { invokeNative, WefterBridgeError } from "@wefterjs/core";

try {
  await invokeNative("camera", "open");
} catch (error) {
  if (error instanceof WefterBridgeError) {
    switch (error.code) {
      case "PERMISSION_DENIED":
        console.error("Camera permission denied");
        break;
      case "NO_BRIDGE":
        console.warn("Running in browser tab");
        break;
      default:
        console.error("Native call failed:", error.message);
    }
  }
}
```

## Unit Testing with `@wefterjs/core/testing`

Mock native bridge responses in Vitest or Jest without a physical device:

```ts
// @vitest-environment jsdom
import { afterEach, describe, expect, it } from "vitest";
import { installMockBridge, uninstallMockBridge } from "@wefterjs/core/testing";
import { getDeviceInfo } from "@wefterjs/core";

describe("Web UI Component", () => {
  afterEach(() => uninstallMockBridge());

  it("fetches mocked device information", async () => {
    installMockBridge({
      __system: (method) => {
        if (method === "getDeviceInfo") {
          return { platform: "android", osVersion: "14" };
        }
        throw new Error(`Unmocked method ${method}`);
      },
    });

    const info = await getDeviceInfo();
    expect(info.platform).toBe("android");
    expect(info.osVersion).toBe("14");
  });
});
```
