## Overview

Before initializing or building a Wefter mobile application, your development environment requires Node.js, JDK 17, the Android SDK, and (optionally for iOS) Xcode.

---

## Required Prerequisites Reference Table

| Tool / Dependency      | Required Version | Environment Variables                | Target Platform  | Purpose                                                                  |
| ---------------------- | ---------------- | ------------------------------------ | ---------------- | ------------------------------------------------------------------------ |
| **Node.js**            | `>= 18.0.0`      | `PATH`                               | All              | Executes Wefter CLI, build scripts, and web bundlers.                    |
| **JDK (Java Dev Kit)** | `JDK 17`         | `JAVA_HOME`                          | Android          | Required by Android Gradle Plugin (AGP) to compile Kotlin code.          |
| **Android SDK**        | API Level `24+`  | `ANDROID_HOME` or `ANDROID_SDK_ROOT` | Android          | Android compilation toolchain and `adb` device bridge.                   |
| **Android ADB**        | Latest           | `PATH` (`platform-tools`)            | Android          | Connects CLI to physical ADB devices and emulators.                      |
| **Xcode**              | `>= 15.0`        | Xcode Command Line Tools             | iOS (macOS only) | Compiles Swift code, builds iOS `.app` bundles, and runs iOS Simulators. |
| **CocoaPods**          | `>= 1.12.0`      | `PATH`                               | iOS (macOS only) | Dependency manager for iOS native pods (optional if using SPM).          |

## Detailed Installation & Configuration

### 1. Node.js & Package Manager

Verify Node.js version in your terminal:

```bash
node -v
# Output should be >= v18.0.0
```

Recommended package manager: `pnpm` (or `npm`/`yarn`).

### 2. JDK 17 Configuration

<Callout type="important">
  **Strict Requirement**: Android Gradle Plugin requires **JDK 17**. Using JDK 8 or JDK 11 will cause Gradle build
  failures.
</Callout>

Set `JAVA_HOME` in your shell profile (`~/.bashrc`, `~/.zshrc`, or Windows Environment Variables):

```bash
# macOS / Linux example
export JAVA_HOME=/path/to/jdk-17
export PATH=$JAVA_HOME/bin:$PATH
```

Verify JDK version:

```bash
java -version
```

### 3. Android SDK & Environment Variables

Set `ANDROID_HOME` to your Android SDK installation directory:

- **Linux**: `~/Android/Sdk`
- **macOS**: `~/Library/Android/sdk`
- **Windows**: `%LOCALAPPDATA%\Android\Sdk`

Export `ANDROID_HOME` and append `platform-tools` (`adb`) to `PATH`:

```bash
# macOS / Linux example
export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/platform-tools
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin
```

Verify `adb` connectivity:

```bash
adb devices
```

## Verifying Setup with `wefter doctor`

Run [`wefter doctor`](/cli/doctor) to automatically audit your development environment:

```bash
wefter doctor
```

Sample successful audit output:

```text
✔ Node.js version (v20.11.0)
✔ JDK version (JDK 17.0.10)
✔ ANDROID_HOME (/home/user/Android/Sdk)
✔ adb executable on PATH
✔ Connected Android device / emulator detected
✔ Xcode command line tools installed (macOS)
```

Before producing production build artifacts, run release verification:

```bash
wefter doctor --release-readiness
```
